# NovaAI 🤖

NovaAI is an AI-powered chatbot built with React and the Google Gemini API.

## Features

- 💬 AI Chat
- 🖼️ Image Upload
- ⚛️ React Context API
- 📁 FileReader for image processing
- 🔄 Async API communication
- 📱 Responsive UI

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Google Gemini API
- Fetch API

🚧 This project is currently under development.
